# Paper Critique Skill

用于论文、基金申请、PDF、DOCX 和 LaTeX 稿件的严格审稿式批评技能。

- 用本技能做深度审阅、挑问题、打磨 reviewer comments。
- 用 [Paper Revision Skill](https://github.com/lachlanchen/paper-revision-skill) 回复审稿意见、修改正文、生成 redline 和 response letter。

仓库： https://github.com/lachlanchen/paper-critique-skill
