# Paper Critique Skill

用於論文、基金申請、PDF、DOCX 與 LaTeX 稿件的嚴格審稿式批評技能。

- 用本技能做深度審閱、挑問題、撰寫 reviewer comments。
- 用 [Paper Revision Skill](https://github.com/lachlanchen/paper-revision-skill) 回覆審稿意見、修改正文、生成 redline 與 response letter。
