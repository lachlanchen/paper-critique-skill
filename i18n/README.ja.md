# Paper Critique Skill

論文、研究費申請書、PDF、DOCX、LaTeX 原稿を厳しく査読するための Codex スキルです。

- このスキルは、レビュー、批評、弱点抽出、査読コメント作成に使います。
- 回答案、本文修正、redline、response letter には [Paper Revision Skill](https://github.com/lachlanchen/paper-revision-skill) を使います。

Repository: https://github.com/lachlanchen/paper-critique-skill
