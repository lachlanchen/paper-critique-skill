# Paper Critique Skill

Codex-Skill für strenge akademische Kritik an Manuskripten, Förderanträgen, PDFs, DOCX-Dateien und LaTeX-Quellen.

- Nutze diesen Skill für Review, Kritik, Schwachstellenanalyse und Reviewer-Kommentare.
- Nutze [Paper Revision Skill](https://github.com/lachlanchen/paper-revision-skill) für Antworten auf Kommentare, Manuskriptrevision, Redlines und Response Letters.

Repository: https://github.com/lachlanchen/paper-critique-skill
