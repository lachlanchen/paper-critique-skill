# Paper Critique Skill

Skill de Codex para crítica académica estricta de manuscritos, propuestas, PDFs, DOCX y fuentes LaTeX.

- Usa este skill para revisar, criticar, desafiar argumentos y escribir comentarios de revisor.
- Usa [Paper Revision Skill](https://github.com/lachlanchen/paper-revision-skill) para responder comentarios, revisar el manuscrito, generar redlines y preparar la carta de respuesta.

Repositorio: https://github.com/lachlanchen/paper-critique-skill
