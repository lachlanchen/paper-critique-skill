# Paper Critique Skill

논문, 연구비 제안서, PDF, DOCX, LaTeX 원고를 엄격한 리뷰어 관점으로 비평하는 Codex 스킬입니다.

- 이 스킬은 검토, 비평, 약점 감사, 리뷰 코멘트 작성에 사용합니다.
- 답변서, 원고 수정, redline, response letter 작성에는 [Paper Revision Skill](https://github.com/lachlanchen/paper-revision-skill)을 사용합니다.
