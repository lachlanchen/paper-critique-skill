# Paper Critique Skill

مهارة Codex للمراجعة الأكاديمية الصارمة للمخطوطات، ومقترحات التمويل، وملفات PDF وDOCX ومصادر LaTeX.

- استخدم هذه المهارة للنقد، والمراجعة، وتحديد نقاط الضعف، وكتابة تعليقات المراجعين.
- استخدم [Paper Revision Skill](https://github.com/lachlanchen/paper-revision-skill) للرد على التعليقات، وتعديل المخطوط، وإنشاء redline وخطاب الرد.

المستودع: https://github.com/lachlanchen/paper-critique-skill
