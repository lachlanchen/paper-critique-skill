# Paper Critique Skill

Compétence Codex pour produire une critique académique stricte de manuscrits, propositions de financement, PDF, DOCX et sources LaTeX.

- Utilisez cette compétence pour relire, critiquer, challenger et écrire des commentaires de reviewer.
- Utilisez [Paper Revision Skill](https://github.com/lachlanchen/paper-revision-skill) pour répondre aux commentaires, réviser le manuscrit, produire un redline et préparer la lettre de réponse.

Dépôt : https://github.com/lachlanchen/paper-critique-skill
