# Paper Critique Skill

Strict reviewer-style critique for manuscripts, grant proposals, PDFs, DOCX files, and LaTeX submissions.

- Use this skill to review, critique, score, challenge, and write reviewer comments.
- Use [Paper Revision Skill](https://github.com/lachlanchen/paper-revision-skill) to answer comments, revise manuscripts, generate redlines, and prepare response letters.
